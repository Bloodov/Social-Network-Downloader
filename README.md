# Telegram-бот для скачивания видео/аудио

Скачивает видео с YouTube, TikTok, Instagram и ещё ~1800 сайтов, которые
поддерживает `yt-dlp` (Twitter/X, VK, Facebook, Pinterest, Reddit, Twitch,
SoundCloud, Vimeo и т.д.) — бот пытается распознать любую присланную ссылку,
а не только из захардкоженного списка.

## Возможности

- **Выбор языка**: при первом /start бот просит выбрать русский или английский;
  переключить язык в любой момент можно командой `/language`. Все сообщения
  бота (кроме админ-команд) локализованы.
- **Обязательная подписка на канал**: если в админ-панели указан канал —
  бот попросит подписаться перед скачиванием и покажет кнопку "Я подписался"
  для проверки. Отключается очисткой поля в панели.
- **Выбор качества**: после отправки ссылки бот показывает кнопки —
  1080p / 720p / 480p (в зависимости от того, что реально доступно у видео)
  или "только аудио (mp3)".
- **TikTok без водяного знака** — `yt-dlp` забирает исходный ролик через
  внутреннее API площадки, а не через веб-плеер с логотипом.
- **Антиспам и защита сервера**:
  - cooldown между запросами одного пользователя (`COOLDOWN_SECONDS`);
  - лимит скачиваний в час на пользователя (`MAX_DOWNLOADS_PER_HOUR`);
  - ограничение числа одновременных загрузок на сервере (`MAX_CONCURRENT_DOWNLOADS`) —
    защищает слабый бесплатный хостинг от перегрузки;
  - лимит длительности видео (`MAX_VIDEO_DURATION`), чтобы не пытаться
    скачивать многочасовые ролики;
  - бан/разбан пользователей (админы обходят все лимиты).
- **Админ-панель** (веб, `admin_panel.py`):
  - счётчики: пользователи, успешные/неуспешные скачивания, забаненные;
  - разбивка по платформам;
  - лента последних загрузок;
  - форма бана/разбана по Telegram ID.
  - Доступна по HTTP Basic Auth (`ADMIN_USER` / `ADMIN_PASS`).
- **Публикация пересланных постов** — самый надёжный способ разослать пост
  со сложным форматированием (жирный, спойлеры, эмодзи, фото). Админ пишет
  боту `/newpost`, затем пересылает готовое сообщение — бот сохраняет его
  как есть (форматирование не трогается вообще, это нативный Telegram).
  В админ-панели пост появляется в списке с кнопкой "Опубликовать" — по
  нажатию бот рассылает его всем через `copyMessage` (без пометки "Переслано
  от"), сохраняя разметку и фото один в один.
- **Рассылка всем пользователям** (реклама, объявления и т.п.) — альтернативный
  вариант прямо из панели: в текстовом поле работает мини-редактор с панелью
  кнопок (жирный, курсив, подчёркнутый, зачёркнутый, спойлер, код, блок кода,
  цитата, ссылка, а также "🧹 Очистить форматирование" — если форматирование
  "залипло" при переходе на новую строку). Плюс можно прикрепить фото.
  Подходит для простых сообщений; для чего-то сложнее — надёжнее способ выше
  (переслать пост через `/newpost`), поскольку в браузерном редакторе
  форматирование иногда ведёт себя нестабильно на мобильных устройствах.
- Те же функции админки продублированы прямо в боте: `/stats`, `/ban <id>`,
  `/unban <id>` (только для ID из `ADMIN_IDS`).
- `/myid` — узнать свой Telegram ID (нужно, чтобы прописать себя в `ADMIN_IDS`).
- `/newpost` (только для админов) — подготовить пост к публикации: бот
  попросит переслать сообщение, сохранит его, дальше публикация — из
  админ-панели.

## 1. Установка локально

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Нужен **ffmpeg** (для склейки видео/аудио и конвертации в mp3):

```bash
# Ubuntu/Debian
sudo apt install ffmpeg
# macOS
brew install ffmpeg
```

Скопируйте `.env.example` в `.env` (или просто экспортируйте переменные
в шелл) и заполните `BOT_TOKEN`, `ADMIN_USER`/`ADMIN_PASS`.

```bash
export BOT_TOKEN="токен_от_BotFather"
export ADMIN_IDS="ваш_telegram_id"
export ADMIN_USER="admin"
export ADMIN_PASS="надёжный_пароль"
python bot.py
```

Веб-панель поднимется на `http://localhost:8080` (или на порту из `PORT`).

## 2. Получение токена бота

1. Напишите @BotFather в Telegram → `/newbot` → следуйте инструкциям.
2. Получите токен вида `123456789:AAExampleTokenHere`.
3. Напишите своему боту `/myid`, чтобы узнать свой Telegram ID для `ADMIN_IDS`.

**Токен и админ уже прописаны в коде** (файл `config.py`) — бот заработает
сразу после деплоя без ручной настройки переменных окружения. Если позже
захотите сменить токен или список админов без правки кода — просто задайте
переменные окружения `BOT_TOKEN` / `ADMIN_IDS` на хостинге, они имеют
приоритет над значениями в `config.py`.

⚠️ Раз токен зашит в код — не выкладывайте репозиторий в **публичный**
GitHub в таком виде: любой, у кого будет доступ к коду, сможет полностью
управлять ботом от вашего имени. Если репозиторий приватный (или бот только
для личного использования на Railway) — это не проблема.

## 3. Деплой на Railway

Проект уже настроен под Railway:

- `Procfile` — говорит Railway запускать `python bot.py` как web-процесс.
- `nixpacks.toml` — ставит `ffmpeg` в образ сборки (без него не будет
  склейки видео+аудио и конвертации в mp3).
- Веб-панель слушает переменную `$PORT`, которую Railway выдаёт
  автоматически — это нужно, чтобы Railway считал сервис "здоровым"
  (health check стучится на `/health`).

Шаги:

1. Залейте проект в GitHub-репозиторий.
2. На railway.app создайте новый проект → **Deploy from GitHub repo**.
3. В настройках сервиса (Variables) добавьте переменные окружения:
   `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_USER`, `ADMIN_PASS`, при желании —
   `COOLDOWN_SECONDS`, `MAX_DOWNLOADS_PER_HOUR`, `MAX_CONCURRENT_DOWNLOADS`,
   `MAX_VIDEO_DURATION`. `PORT` Railway подставит сам, руками задавать не нужно.
4. Деплой запустится автоматически. В логах сервиса должно появиться "Бот запущен".
5. Откройте выданный Railway URL (Settings → Domains → Generate Domain) —
   это адрес админ-панели, войти по `ADMIN_USER`/`ADMIN_PASS`.

**Про "бесплатность" Railway.** Постоянного бесплатного тарифа у Railway
сейчас нет: доступен 30-дневный триал с $5 кредитов, дальше — тариф Hobby
($5/мес, в который тоже включены $5 кредитов на использование). Для такого
лёгкого бота (один процесс, малый трафик, скачивания — не постоянная
нагрузка) $5 кредитов обычно с запасом хватает на месяц, но это не
гарантированно бесплатно навсегда — стоит время от времени проверять баланс
использования в Railway Dashboard. Актуальные условия смотрите на странице
тарифов Railway (railway.app/pricing).

**Про базу данных.** SQLite-файл (`bot.db`) хранится на диске контейнера.
Он переживает рестарты, но может быть сброшен при пересоздании контейнера
(например, после смены плана). Если статистика и список банов важны на
годы вперёд — подключите Railway Volume и укажите путь к нему в `DB_PATH`.

## Важные ограничения

- **Обязательная подписка**: чтобы проверка подписки работала, добавьте бота
  администратором в канал, который укажете в поле "Обязательная подписка" в
  панели. Без прав администратора Telegram не даёт боту проверять список
  подписчиков — в таком случае бот пропускает проверку (не блокирует
  пользователей), но пишет предупреждение в логи.
- **Лимит размера файла.** Обычный Telegram Bot API не даёт ботам отправлять
  файлы больше **50 МБ**. Для больших файлов нужен собственный локальный
  Bot API сервер (проект tdlib/telegram-bot-api, лимит вырастет до 2 ГБ) —
  это уже отдельная инфраструктура поверх Railway.
- **Instagram** часто требует авторизации для приватных/ограниченных
  аккаунтов — для таких случаев `yt-dlp` поддерживает передачу cookies
  (`--cookies cookies.txt`), можно добавить в `_extract_info_sync`/`_download_sync`,
  если понадобится.
- **Авторские права.** Скачивайте только то видео, на распространение
  которого у вас есть право (свой контент, разрешённая лицензия и т.п.).
- `yt-dlp` регулярно обновляется вслед за изменениями в API площадок — если
  скачивание массово перестало работать, в первую очередь обновите пакет:
  `pip install -U yt-dlp` (на Railway достаточно снять/поставить версию в
  `requirements.txt` и передеплоить).

## Структура проекта

```
tg_downloader_bot/
├── bot.py            # логика бота: команды, скачивание, антиспам, язык, подписка
├── config.py           # токен бота и ID админов
├── locales.py          # тексты бота на русском и английском
├── database.py         # SQLite: пользователи, история загрузок, баны, настройки
├── admin_panel.py      # веб-панель на Flask + рассылка + настройка подписки
├── requirements.txt
├── Procfile            # команда запуска для Railway
├── nixpacks.toml       # установка ffmpeg при сборке на Railway
├── .env.example
└── README.md
```
